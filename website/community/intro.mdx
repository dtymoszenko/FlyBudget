# Community

FlyBudget is intended to be community and collaboration focused. Whether you have found a bug, have an idea for a new feature, or just want to follow along, here is where to get involved!

Want to help build FlyBudget? Start with the [Contributing guide](./contributing/index.mdx), which covers our [AI usage policy](./contributing/ai-usage.mdx) and [commit & PR guidelines](./contributing/commit-conventions.mdx).

Curious how we protect your data and bank connections? Read about [Security](./security.mdx), including how to privately report a vulnerability.
