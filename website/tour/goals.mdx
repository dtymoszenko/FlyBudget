# Goals

Goals shows each savings target as a card with a progress bar, how much is left, and (when
you set a target date) how much to put aside each month to get there on time. Totals across all
goals sit at the top.

Choose **Add Goal** to create one, and click a goal to edit it. See [Goals](/docs/goals) in the
guide.
