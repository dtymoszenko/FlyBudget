# Goals

**Goals** tracks what you're saving toward: an emergency fund, a trip, a new laptop. The cards
at the top add up everything you've saved, your targets and how many goals you've reached.
Each goal shows its progress and, when it has a target date, how much to set aside each month
to get there on time.

![The Goals page](/img/screenshots/goals.webp)

A goal can follow an account's balance, so it updates by itself as you save.

Read [Goals](/docs/goals) in the guide.
