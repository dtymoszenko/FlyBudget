# Rules

The Rules page lists your rules in the order they run, each summarized in plain words, like
"If payee contains _Netflix_, set category to _Streaming_".

- **Add rule** opens the rule editor, which previews the transactions a rule would match as you
  type.
- Drag rules to change their order, and switch them on or off.
- **Run rules** applies your rules to existing transactions, after showing you what would
  change.

Read [Rules](/docs/rules) in the guide to learn how conditions, actions and order work.
