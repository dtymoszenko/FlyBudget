# Goals

Goals track savings targets, like an emergency fund, a trip or a down payment.

Choose **Goals → Add Goal** and enter:

- **Name** and **target** amount.
- **Saved so far**, if you've already started.
- A **target date** (optional). FlyBudget works out how much to set aside each month to get
  there on time.
- A **linked account** (optional). The goal's progress then follows that account's balance, so
  it updates as you save.

Pick an icon and color to tell your goals apart at a glance.
