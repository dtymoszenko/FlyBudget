# Installing FlyBudget

There are three ways to run FlyBudget. They all run the same app; they differ in where your
budget is stored and which devices can open it.

| Option                                    | Your budget lives…                     | Open it from…                            |
| ----------------------------------------- | -------------------------------------- | ---------------------------------------- |
| [Desktop app](#desktop-app)               | in a file on your computer             | that computer                            |
| [Self-hosted server](#self-hosted-server) | on a server you run (home server, VPS) | any browser, including your phone        |
| [From source](#from-source)               | in the project folder                  | the computer running it (for developers) |

Not sure? Start with the desktop app. You can move to a server later: download a
[backup](./backups) and restore it there.

:::tip[Just looking?]

[Try the demo](pathname:///demo/) runs FlyBudget in your browser with a sample budget. There's
nothing to install, and nothing you change is saved.

:::

## Desktop app

1. Go to the [download page](/download) and get the installer for your computer.
2. Run it. Windows may say the publisher is unknown ("Windows protected your PC"): FlyBudget
   isn't signed with a paid code-signing certificate yet. Choose **More info → Run anyway**.
   Every release is signed another way, so you can check that your download is genuine (see
   [Verifying your download](/community/security#verifying-your-download)).
3. Open FlyBudget. The first time, it asks how you'd like to add your accounts; continue with
   [Getting started](./getting-started).

The desktop app keeps your budget in a single file, `budget.db`, in your user folder:

| System  | Folder                                    |
| ------- | ----------------------------------------- |
| Windows | `%APPDATA%\FlyBudget`                     |
| macOS   | `~/Library/Application Support/FlyBudget` |
| Linux   | `~/.config/FlyBudget`                     |

The same folder holds `credentials.key`, the key that encrypts your bank connections, itself
protected by your operating system's keychain. You don't need to touch either file: use
**Settings → Data → Download Backup** to back up your budget.

### Updating

Download the new version from the [download page](/download) and install it over the old one.
Your budget stays where it is, and FlyBudget updates it for the new version when it starts.

## Self-hosted server

Run FlyBudget in Docker on a home server, a NAS or a small cloud machine, and open it in any
browser with a password you choose. This is how you use FlyBudget on your phone or share a
budget with your household.

```bash
openssl rand -base64 32 > flybudget_data_key.txt   # the key that protects bank credentials
docker compose up -d                                # with docker-compose.yml from the repository
```

Then open `http://<your-server>:3001`, enter the setup code from `docker logs flybudget`, and
choose your password. The [self-hosting guide](/community/self-hosting) covers every step,
HTTPS, backups and updates.

## From source

For trying the latest changes or contributing. You need [Node.js](https://nodejs.org/) 24 (the
version FlyBudget is built and tested with) and Git.

```bash
git clone https://github.com/dtymoszenko/FlyBudget.git
cd FlyBudget
npm ci && npm ci --prefix client && npm ci --prefix server
npm run dev   # opens on http://localhost:5173
```

Your budget is stored in `server/budget.db`. Bank credentials aren't encrypted in this mode, so
use the desktop app or a server for your real budget. See
[Contributing](/community/contributing) for the rest.
