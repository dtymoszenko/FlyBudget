# Frequently asked questions

## General

### Is FlyBudget really free?

Yes. FlyBudget is free and open-source software under the
[AGPL-3.0 license](https://github.com/dtymoszenko/FlyBudget/blob/main/LICENSE). The only
possible cost is a bank connection service, if you choose to use one (see
[Connecting a bank](./bank-sync)).

### Where is my data stored?

In a single SQLite database file: on your computer for the desktop app, or in the data
directory of your self-hosted server. Nothing is sent to FlyBudget; there is no FlyBudget
server to send it to.

### Can I try it without installing anything?

Yes: [Try the demo](pathname:///demo/) runs the real app in your browser with a sample budget.
Nothing you change is saved or sent anywhere, and closing the tab throws it away. Bank connections
need the installed app.

### Can I use it on my phone?

Yes, through a [self-hosted server](/community/self-hosting): open it in your phone's browser.
Every page has a layout made for small screens. See [On your phone](./phone).

### Can more than one person use the same budget?

A self-hosted server can be opened from several devices at once with the same password. There
are no separate user accounts yet.

### Does FlyBudget support multiple currencies?

Each budget uses one currency. You can choose its symbol in **Settings → Preferences**.

### Can I move my budget to another computer, or to a server?

Download a [backup](./backups) on the old one and restore it on the new one. It works between the
desktop app and a self-hosted server in either direction. Connect your banks again afterwards.

### Can I undo a change?

Press <kbd>Ctrl</kbd>+<kbd>Z</kbd> (<kbd>⌘</kbd>+<kbd>Z</kbd> on a Mac). See
[Undo](./settings#undo).

## Troubleshooting

### The desktop app says "FlyBudget is starting up again"

Its built-in server stopped for a moment and is restarting. It usually comes back on its own
within a few seconds. If it doesn't, close FlyBudget and open it again.

### My self-hosted server shows "can't reach the server"

The page is fine; the server isn't answering. Check that the container is running
(`docker ps`) and what it logged (`docker logs flybudget`). Anything you add in the meantime is
kept on your device and sent when it's back (see [Working offline](./offline)).

### I forgot my server password

See [Your password](/community/self-hosting#your-password) in the self-hosting guide: a command
on the server removes it, and you then set a new one.

### Windows or macOS won't open FlyBudget the first time

FlyBudget isn't signed with a paid Microsoft certificate or notarized by Apple yet. On Windows,
choose **More info → Run anyway**. On a Mac, open **System Settings → Privacy & Security** and
choose **Open Anyway** next to FlyBudget (see [Installing](./installing#macos)). You can check that
the download is genuine with its signature (see
[Verifying your download](/community/security#verifying-your-download)).

### FlyBudget won't start from the AppImage on Ubuntu

Ubuntu 24.04 and later block the sandbox Electron apps use when they run from an AppImage. Install
the .deb instead (see [Installing](./installing#linux)).

### Imported transactions have the wrong sign, or the wrong dates

See [What FlyBudget understands](./importing#what-flybudget-understands) and
[Credit cards](./importing#credit-cards) on the importing page.

### A transaction didn't get the category I expected

Rules run top to bottom and a higher rule wins; a category you picked yourself always stays. See
[Order matters](./rules#order-matters).

## Getting help

### I found a bug or have an idea

Please [open an issue on GitHub](https://github.com/dtymoszenko/FlyBudget/issues). For security
problems, follow the [security policy](/community/security) instead so they can be fixed
privately.

### How can I help?

See [Contributing](/community/contributing). Bug reports, documentation fixes and code are all
welcome.
